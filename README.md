## 🚀 Deployment to Vercel

This repository is pre-configured with `vercel.json` for zero-configuration, seamless deployment on [Vercel](https://vercel.com).

### Option 1: Deploy via Vercel Dashboard (Recommended)

1. Push this repository to your GitHub account:
   ```bash
   git add .
   git commit -m "feat: complete Shawarma Moods Christmas 2026 pitch website"
   git push -u origin main
   ```
2. Navigate to your [Vercel Dashboard](https://vercel.com/new).
3. Click **"Add New..."** → **"Project"** and select your GitHub repository.
4. Vercel automatically detects the **Vite** framework preset:
   - **Build Command:** `npm run build` (or `vite build`)
   - **Output Directory:** `dist`
   - **Install Command:** `npm install`
5. Click **Deploy**. Your live site URL will be ready in under 60 seconds!

### Option 2: Deploy via Vercel CLI

```bash
# Install Vercel CLI globally
npm install -g vercel

# Preview Deployment
vercel

# Production Deployment
vercel --prod
```

## 📐 Project Architecture & Narrative Order

The website presents the proposed campaign in the exact sequence specified in `AGENTS.md`:

1. **The Emotional Hook (`#the-why`)**: Montréal winter conditions vs. the warmth and dignity of food.
2. **The Core Mechanism (`#mechanism`)**: Clear 3-step customer-funded breakdown (Buy 2, Keep 1, Donate 1).
3. **The Shared Commitment**: Shawarma Moods matches with +$1.00 cash per verified meal.
4. **The 1,000 Challenge (`#tracker`)**: Interactive slider (0 to 2,000 meals) and milestone unlock indicators.
5. **Community Delivery Plan**: Target Dec 23, HACCP thermal chain (>60°C), and ethical dignity filming guidelines.
6. **Creator Amplification**: Local Montréal foodie & student ambassador tiers; zero false viral promises.
7. **B2B Business Expansion**: Model demonstrated through the Kin Academy course enrollment case study.
8. **Supporting Commercial Offers**: $10 promotional shawarma, student combo, and 10-person Family Holiday Box.
9. **Interactive Unit Economics (`#economics`)**: Real-time margin calculator and sensitivity scenarios (350 / 1,000 / 2,000).
10. **Video Production Suite (`#video-suite`)**: 60-second public trailer & 5-minute owner pitch video scripts.
11. **Creative Poster Showcase (`#posters`)**: High-res lightbox viewer for `/Buy One, Give One Shawarma.png`.
12. **Owner Decision Gateway (`#owner-decision`)**: Pre-launch readiness checklist and risk mitigation matrix.
